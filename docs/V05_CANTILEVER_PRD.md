## 最新用户确认

仅普通等厚水平悬挑板，左右共用。面筋自由端向下，底筋独立终止，不连接成U形筋。不含反坎、下挂、斜板、变厚或内跨板面高差。

| 模式 | 支座面筋 | 独立身份 |
|---|---|---|
| 1 | 无内跨，向上弯 | 面筋、底筋 |
| 2 | 无内跨，向下弯 | 面筋、底筋 |
| 3 | 全部内跨伸出 | 内跨伸出筋、底筋 |
| 4 | 内跨伸出＋独立附加筋 | 伸出筋、附加筋、底筋，分别保留规格/间距/标注 |

模式4同路径，不错层，不串接，不合并身份。SVG紫色虚线仅为辨识。截止符号始终按世界坐标向下，文字要求覆盖旧SVG朝上表达。无内跨允许突出梁，不自动移动梁或改长度；仍检查有限值、相切、零长度及本筋非法几何。允许上弯和允许突出属于工具绘图行为，不声称图集推荐。

## 参数表

全部毫米；工程控制长度首次留空，用户输入，不自动推荐。本聊天中用户已明确同意以下A/V/E/F/B输入及投影起算口径。

| 参数 | 起算和含义 | 状态 |
|---|---|---|
| L、h | 悬挑侧梁面至自由端、等厚板厚 | 计算必需；CAD轮廓适配待实现 |
| b | 两侧梁面间水平宽度，内跨梁面局部X=-b | 确认；不生成梁宽尺寸 |
| Lin | 内跨梁面至附加筋截止水平距离，截止X=-(b+Lin) | 确认；标注值仅Lin |
| A | 悬挑侧梁面至无内跨支座竖段中心线水平距离 | 已确认用户输入 |
| V | 面筋水平中心线至支座端点竖向投影 | 已确认，圆弧计入投影 |
| E | 内跨侧梁面至伸出筋绘制终点水平距离，模式3/4均需 | 已确认用户输入 |
| F | 面筋水平中心线至自由端下弯端点竖向投影 | 已确认用户输入 |
| B | 悬挑侧梁面至底筋支座端点水平距离 | 已确认用户输入，底筋独立处理 |
| 分组直径/间距 | 面筋、底筋，模式4再含独立附加筋 | 已确认，显示尺寸独立 |
| c、R、显示线宽、点筋大小、字高、图层 | 复用用户级高级设置 | 已确认，不另建共享系统 |
| 截止符号 | 水平投影26、向下投影26 mm | 用户最新答复确认；不混入Lin/控制长度 |
| 点筋原则 | 只在悬挑板侧，外角必需，从外向内，满足最大间距且尽量少 | 已确认原则；具体布置边/下角/梁端余量仍待答复 |

起算点见 [简图](V05_LENGTH_ORIGINS.svg)。A/V不使用梁侧挂板L/V的定义。投影、中心线展开长度、计算直径及显示宽度分别处理。模式4共同表达路径以主面筋（内跨伸出筋）为基准，附加筋不按自身规格另行错层；底筋按自身计算直径偏移。该重合表达不作结构保护层合格判断。

点筋待答复问题：是否为上下水平边＋外侧竖边，还是仅上下两排；上角与面筋圆弧内缘相切、下角位于底筋端附近且与底筋内缘相切；靠梁端余量是否≤输入最大间距。未将这些问题写成已确认，也不直接套V0.4点筋算法。
