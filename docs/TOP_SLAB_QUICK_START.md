# 反坎带飘板使用说明

更新日期：2026-11-05。适用于当前第一版；未发布1.0。板上120/150预设只针对本组合节点，旧板上反坎的预设不变。

## 使用步骤

1. 从[预览版Releases](https://github.com/ichcoase/WallDetailTool/releases/tag/v0.6.0-preview.1)下载DLL及校验文件，或使用下文本机工件，在新图或图纸副本中用 `NETLOAD` 加载。源码仓库不再跟踪bin，构建产物在Releases单独提供。同一会话已有旧DLL时需在新的CAD会话加载新版，保留未保存工作。
2. 运行 `WDTTOPSLAB` 或点工具条“反坎带飘板”，选择底部“梁上”或“板上”，填写参数。
3. 点击“选择轮廓并生成”，一次选完L形边界并回车。闭合输入直接识别和生成；仅底部开放时，高亮源轮廓并显示临时虚线底边，提示“虚线为反坎底部计算边界，确认生成？[确认/重选] <确认>”，回车直接生成，选“重选”可重新选择。Esc或失败返回参数窗口并保留本次草稿；取消窗口丢弃草稿。
4. 核对普通节点块、原始轮廓、三根独立线筋、两类点筋、规格引线和尺寸。原轮廓保留，底部梁板不绘制。

仅支持WCS二维、水平/竖直边构成的标准顶部L形，输入为单个轻量多段线或一组首尾相接的LINE，不混选。自动接受完整闭环，以及只缺反坎底部封口边的开放链，无需切换模式。开放两端须在两侧竖边底部、同一最低Y位置；缺侧边/顶边/自由端边、两端不等高、多缺口或多余对象等均不能自动修复。同向共线拆边可识别。

虚线只提示计算底边，生成后清除；不修改源多段线Closed、不添加永久封口线，也不加入生成块。方向和两种厚度、总高、飘出长度由轮廓读取，开放输入的高度/底部锚固以虚拟底边起算，与同尺寸闭环一致。仅毫米或无单位（按毫米），不支持本节点两点定位或输入尺寸自动重塑轮廓。

## 当前默认参数

| 参数 | 梁上 | 板上 |
|---|---|---|
| 三组线筋、两类点筋规格 | 优先有效成功记录，其次共享规格 | 优先有效成功记录，其次共享规格 |
| A 顶部水平直段 | 自动 | 自动 |
| B 向下弯折直段 | 60 mm试用值 | 60 mm试用值 |
| 外侧底部长度 | 直锚300 mm | 水平直段L外150 mm |
| 内侧底部长度 | 默认跟随外侧，可独立修改 | L内150 mm，可留空同L外 |
| 底部板厚h | 不显示 | 120 mm |
| 板底至水平筋中心H | 不显示 | 保护层＋线筋显示宽度/2；工厂设置为31 mm |

板上按h、H、L外、L内顺序填写，须满足0<H<h。L从底部弯弧水平切点量至端头；h是底部连接板厚，不能用顶部飘板厚度代替。已有本类型有效成功参数优先，更新DLL不会将已记忆参数强制改成120/150。梁板记录分开，只有生成事务成功才保存。本表均为可修改试用值，不代表工程设计推荐。

## 当前图面规则

- 外侧连续筋、内侧竖筋、飘板下筋三个身份独立，阴角交叉弯折保留。
- 红蓝顶部水平段可见外缘净距10 mm；蓝色端头到左角点筋圆外缘最短净距10 mm，随方向镜像。这里颜色仅用于审阅图辨识。
- 顶部点筋同标高：外侧角点贴外侧竖筋内缘，其余顶点贴内侧筋水平段下侧；两侧按原输入间距同步向下。飘板点筋不进入反坎节点域。
- 两项水平尺寸在顶部共线，界线从轮廓顶面引出；内侧线筋在内侧标注，每类点筋用一个规格文字引向两排。
