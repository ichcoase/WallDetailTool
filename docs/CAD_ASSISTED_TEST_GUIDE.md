# Codex 操作 AutoCAD 测试指南

本指南用于用户要求 Codex 在真实 AutoCAD 中协助测试时。先遵循项目 [AGENTS.md](../AGENTS.md)、本轮用户指令及当前可用电脑操作工具的说明；本指南不自动授权启动新开发阶段，也不替代结构工程师审核。

## 每次开始前

1. 阅读相关需求、架构、开发计划、源码和当前验收清单，检查未提交修改；明确本轮测试范围及预期结果。确认用户已授权本轮操作 CAD，历史某一轮“不启动 CAD”等约束按其适用范围理解，不覆盖用户新的明确指令。
2. 使用当前环境提供的电脑操作技能和工具连接真实 AutoCAD；先查看窗口及当前图纸，确认版本、活动文档和有无正在进行的命令。工具接口可能变化，以当次返回文档为准。遇权限或界面阻碍如实报告，不绕过系统或 CAD 安全限制。
3. 使用新图或明确的测试副本。保留用户原图及当前未保存工作，不覆盖用户 DWG、不自动关闭 AutoCAD、不改全局信任或安全设置；不删除未知文件。需要 DLL 时核对本轮实际交付路径与哈希，确认当前已加载版本；不要假设每次都能在同一 CAD 进程中替换已加载 DLL。
4. 示例参数仅用于图面与软件测试，不是设计推荐。结构规则、弯折及锚固应由工程师审核；缺少工程依据时不得给出结构合格结论。

## 实际操作建议

- 新建测试图时选择合适的毫米模板；选中已打开的原图前先确认，避免误操作。按节点要求绘制闭合轮廓，并在 CAD 中核对识别出的尺寸、方向和单位。
- 使用 `NETLOAD` 加载项目的.NET DLL，再运行对应命令；不要用APPLOAD代替。加载提示和 CAD 的安全选择由当前环境及适用权限决定，不更改安全配置。各参数逐项输入，**等待界面完成响应并读取实际值后再继续**；不要把发送输入等同于填写成功。电脑操作可能通过剪贴板输入，连续快速输入曾出现延迟、串值及粘贴了原有剪贴板文字；生成前必须逐项核对，避免把用户剪贴板内容记入日志或图纸。
- 弹窗可能是独立窗口；通过窗口列表选中实际的参数窗口，必要时根据截图操作。若截图含多个区域，使用工具返回的对应区域标识。CAD 坐标、控件与焦点按实际界面重新确认，不能照搬旧截图坐标。
- 运行生成后读取 CAD 命令行和图面，确认是否真的生成，必要时缩放至完整范围。检查本轮相关的轮廓、钢筋、点筋、尺寸、规格文字、引线和遮挡，并按变更选择必要的左右、上下、取消、撤销重做、保存重开、单位及多文档验证。截图不能证明实体属性、持久化或工程正确。
- 交付时优先提供真实 CAD 的整体图，必要时提供交接处局部放大图，并区分截图、生成成功、已逐项检查和用户验收。若工具只能在操作过程展示截图，说明展示限制，不声称已附可保存图片。只保留本轮确需的少量图片或测试图，明确路径和用途；自动保存文件可能由 CAD 自行产生，不承诺零占用。清理只针对已确认属于本轮且用户授权可清理的文件，保留未知文件及用户资料。
