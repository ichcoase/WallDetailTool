# 普通悬挑板试用

```text
内跨     梁宽b          悬挑板1500×200（向右）
  ←E→ |←───→|────────────────┐ 面筋
 ←Lin→|     |               │ 自由端自动F
      |     |──────────────── 底筋独立
            ↑悬挑侧梁面     自由端
```

工厂各线筋φ8@150、点筋φ6@200；b300、A180、V250、E600、B200、Lin450按模式启用。①无内跨向上、②无内跨向下：A从悬挑梁面至支座竖筋中心线，V从面筋水平中心线至端头，含圆弧投影。③全部内跨伸出、④内跨伸出＋独立附加：E从内跨梁面至伸出筋绘制终点；④Lin从内跨梁面至附加筋截止，不含b及26×26符号。

B从悬挑梁面至底筋支座端头；b只定位不标宽。F不输入，面筋端头自动高于底筋水平中心线10mm，不标自由端F；无内跨支座显示V数字。④两组面筋同路径保留独立身份，不是串接/搭接。

先选左右/四模式，按焦点说明调整；选局部矩形/U或点1500×200的对角点，右伸左边连接、左伸右边连接。L/h取实际范围。恢复只改当前模式；切回保留其他原始草稿；帮助不用联网。生成后核对上下点筋共X、一条整组规格、紧凑四区引线，④Lin/L共Y。

只有普通水平等厚板，无反坎/下挂/变厚/内跨高差。两排点筋及自动F仍按原计算，不能容纳拒绝；允许支座筋突出梁是用户绘图选项，仍需人工审核，不代表规范推荐。
