# 梁上反坎试用

```text
       ┌───┐ 反坎局部范围300×400
       │ ∩ │ 连续线筋
梁顶 ──┴─│─┴── 连接面
         ↓ 两端从连接面向下量各自锚固
```

线筋φ8@150、点筋φ6@200、左/右锚固300为工厂试用值；已保存值/共享规格优先。锚固是连接面至该端端头的长度，不自动计算La。保护层、显示尺寸和R仍用原高级设置。

打开“梁反坎/下挂”选择向上、默认轮廓输入，选既有300×400局部矩形或向梁开口U；也可改“两点矩形”，点两个对角点，下边为连接边。参数先定、范围后取，取消不保存。生成后核对原图保留、普通块及规格位置。

局部范围不能证明完整梁内边界合格；试用值不保证任意轮廓适用。WCS二维、毫米；真实CAD事务专项仍待验收。
