# 梁下下挂试用

```text
         ↑ 两端向上进入梁
梁底 ──┬─│─┬── 连接面
       │ ∪ │ 下挂局部范围300×400
       └───┘
```

线筋φ8@150、点筋φ6@200、左/右锚固300。各锚固从连接面向上量至端头；与梁上共用原计算，仅方向适配，不是另一套排筋规则。

“梁反坎/下挂”切向下（旧下挂命令仍预选向下），选择轮廓或两点。两点矩形上边是连接边，两点顺序不限。切回向上保留本次另一方向草稿；恢复只改当前方向，取消丢弃本次修改。完成后核对普通块和正向文字。

局部300×400仅试画范围，梁内审核、WCS二维/毫米及原几何限制不变，不自动推荐锚固。
