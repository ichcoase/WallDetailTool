# 板下下挂试用

```text
板顶 ─────────── H从板顶至水平筋中心线
        ─┐ ┌─ 两端水平筋
板底 ───┬│ │┬─── 连接面
        └───┘ 下挂300×400
```

线筋φ8@150、点筋φ6@200、局部h200、H工厂31、左右L300。H从板顶向下至水平筋中心线，L仍是切点至端头水平直段，不包含圆弧。与板上共用计算，方向不同不改参数定义。

“板反坎/下挂”选向下或使用原板下命令，先填参数再选局部轮廓；两点300×400上边为连接边，h必须输入。查看帮助/切换方向不会保存DWG，成功生成才保存本类型。

完整截面板厚依原识别，H和R等仍须合法；两端数字不显示H或圆弧展开长。WCS二维/毫米，工程审核和CAD专项不能用示意代替。
