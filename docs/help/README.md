# 本地节点试用帮助

从当前窗口点“本节点示例与帮助”可直接查看当前原生示意和说明，无需联网。以下六份为对应的审阅版；图为起算关系示意，不按比例，不是工程配筋建议。

- [梁上反坎](beam-up.md)
- [梁下下挂](beam-down.md)
- [板上反坎](slab-up.md)
- [板下下挂](slab-down.md)
- [梁侧挂板](beam-side.md)
- [普通悬挑板](cantilever.md)

通用步骤：先选方向、构造和输入方式；调整需要变化的数字，焦点说明解释起算点；必要时恢复当前模式试用值；选择已有局部矩形/开放U轮廓，或点两个对角点生成。两点只定义局部范围，不画混凝土、不提供完整支座边界。第二点取消不生成；生成结果需人工核对。共享设置仍用原工具条高级设置；试用预设不重置共享值。

只支持现有WCS正交二维范围；不支持的UCS/视图仍拒绝。旧梁/板固定毫米，梁侧/悬挑沿原单位确认。空间不足修改参数，不自动缩R或改变几何。不改原图或历史块，不输出规范合格结论。
