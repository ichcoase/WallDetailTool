# 板上反坎试用

```text
        ┌───┐ 反坎300×400
板顶 ───┴│ │┴─── 连接面
        ─┘ └─ 两端水平筋
板底 ─────────── H从板底至水平筋中心线
```

线筋φ8@150、点筋φ6@200、局部板厚h200、H工厂31、左右L300。H为板底至水平筋中心线；L左/右各从水平圆弧切点至端头，不含圆弧。无记录H沿用既有保护层＋显示宽度/2规则，共享值变化后首次H可能不同；恢复填31只是试用。

“板节点”向上，选已有局部矩形/开放U或两点300×400；两点下边连接楼板且必须有h。完整截面仍按原识别取得板厚，不以试用h冒充真实尺寸。焦点查看H/L说明，再生成。

水平端部会分别显示各L纯数字。取消不写成功记录；WCS二维/毫米，放不下仍报错。
