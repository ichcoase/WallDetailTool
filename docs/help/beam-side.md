# 梁侧挂板试用

```text
梁内端 ┐──────┐  向右挂板局部300×600
      V│      │  左边为连接边
梁内端 ┘──────┘
        L为梁内水平＋圆弧＋V
```

线筋φ8@150、点筋φ6@200、L400、V100。L沿中心线包含梁内水平、90°圆弧和竖直V；V只从圆弧切点至端头，不含R。上下共用L/V，低频区可改上下弯折世界方向及规格标注侧，左右镜像不翻转世界上下方向。

首次局部/向右；先定参数后选局部矩形或U。两点300×600时右伸用左边连接、左伸用右边连接，仅局部且明确禁用完整模式。完整模式需原有完整梁/块体轮廓及必要连接面确认，不能凭两点伪造。

保留水平规格引出与侧别规则，梁内两端各显示直段V。点筋不因界面变化重排；非毫米需原单位解释确认。局部梁边界未知，需人工审核。
