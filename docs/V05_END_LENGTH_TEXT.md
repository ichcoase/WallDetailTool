# V0.5 端部长度TEXT

2026-10-29，基线55a6e99，追加在既有Lin/L等高提交之后，不覆盖该提交。

## 用户确认

| 节点 | 生成位置和数量 | 数值口径 |
|---|---|---|
| 普通悬挑板模式1/2 | 支座端真实竖段旁，1处 | 输入V，包含圆弧在投影内；不是V-R、直段或自动F |
| 普通悬挑板模式3/4 | 无新增端部长度字 | 不给自由端自动F加字，不因重合附加筋重复标注 |
| 板上反坎/板下下挂 | 两端水平尾段旁，各1处 | 各自L左/L右，从水平圆弧切点至端头，不含圆弧 |
| 梁侧挂板 | 梁内上下端竖直直段旁，各1处 | 输入V，即切点至端头直段；不是总展开L或V+R |

参考截图竖排200表达。仅新增原生单行TEXT，内容只有毫米数值，不加mm、引线、箭头或尺寸。数值沿用0.###格式，无多余小数尾数。竖段文字Rotation=π/2，水平段Rotation=0；左右/上下仅适配位置，字形不镜像、不倒置。字体、毫米字高、图层来自各节点已有标注设置。两端即使数值相同也分别显示一次。

## 实现与边界

EndLengthAnnotationGeometry为各节点提取真实端段和对应参数，保留不同V/L定义；端段坐标只用于定位，不以其测量值代替参数值。悬挑板只读取主面筋支座段，避免重复筋叠字。Slab适配器读取已经完成NodeOrientation反射的真实端段，板上/下共用计算。

EndLengthAnnotationCad复用EnsureUpstandTextStyle、图层及TryAppendAnnotation服务。先用实际DBText.GeometricExtents得到旋转后的文字范围，再在端段中部附近选择位置。优先放在钢筋外侧，检查本次块内线筋/圆弧/显示宽度、点筋、规格文字、已加长度字和尺寸实际范围；有冲突时只调整新增文字的位置，不动钢筋或既有标注。原生新尺寸若暂时没有范围，仅计算本次新块内尺寸图形以便测量。不扫描或修改历史块。

候选位置有限，空间仍不足、字体/尺寸范围无法取得或图层锁定时，按现有可选标注事务报告具体遗漏，保留其余有效结果；不静默叠字、不移动钢筋或偷偷缩字。实际AutoCAD字体、曲线相交和尺寸范围的动态行为尚未运行，不将纯计算回调测试扩大为CAD碰撞验收。

悬挑板和梁侧挂板的毫米端段按请求比例转换一次；显示文字仍用毫米参数值。板上/下旧流程已生成的顶点本身是图形坐标，不能再次乘比例；新增文字直接锚定这些顶点，字高和留白按当前INSUNITS毫米比例转换。旧板节点本身固定1单位=1mm的排筋流程及原标注并未在本轮升级成非毫米计算；不据新增文字宣称旧流程整体单位适配完成。未知单位无法换算时明确报告文字未生成，不改图纸单位。

所有新增文字经本次生成的普通块及父事务提交，跟随块参与撤销/重做；不另写参数、不修改成功记录，不重画旧块。Lin/L共Y、紧凑规格布局、排筋、弯折、偏移、自动F及既有参数定义保持55a6e99。
