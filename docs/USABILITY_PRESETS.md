# 现有节点完整试用预设（2026-10-30）

这些是可修改的绘图试用值，不是图集推荐、锚固计算或规范合格结论。SVG只提供界面方向，数值按既有源码及本轮补齐项确定。轮廓不适合时仍报告原几何错误，不改输入、缩R或移动钢筋。所有长度/直径/间距输入均为mm。

## 优先级及恢复范围

1. 当前DWG、本节点类型有效的上次成功参数。
2. 当前用户已有共享规格及高级设置（该类型支持的字段）。
3. 下表首次试用值。

“恢复试用预设”仅替换当前方向/模式启用的数字输入，不改变其他模式的原始文字草稿、弯折方向选择、输入方式、单位选择、共享保护层/显示尺寸/R/字体/字高/图层，不写DWG或用户设置。恢复使用表中明确数字；它不是重新读取共享规格。取消/关闭丢弃本次草稿，生成成功才按原事务写本类型记录。左右方向沿用梁侧/悬挑原有同参数语义；各构造模式草稿独立，梁/板上下方向草稿独立。
