# V0.5 直角标注布局修订

## 2026-10-29 布局更新

最新以 [紧凑布局](V05_COMPACT_LAYOUT.md) 为准：下方靠板内半区，允许向中部出字，底筋可改选真实直段锚点；上方按实测文字范围与折点共同收紧，不再放到全节点包围盒外。90°、真实双排点筋公共连接、规格统计和正向文字继续保留。以下是a3bc0eb之前的历史布局与证据，不作为当前外侧出字要求。

2026-10-28，源码基线5362b96。仅改标注布局；排筋、预设、自动F、参数保存和既有块保持原实现。本轮确认覆盖斜向引出、底筋直引及点筋单接触点的限制。

## 最新用户确认

所有规格从真实钢筋位置先竖直引出，再转水平；正向TEXT位于水平线上，保留交接斜杠。水平线最后终点由CAD实测TEXT范围确定，不移动钢筋来迁就标注。

| 钢筋身份 | 右悬挑 | 左悬挑 | 锚点 |
|---|---|---|---|
| 内跨伸出筋（模式3/4） | 内跨侧上方，先上后左 | 内跨侧上方，先上后右 | 本组真实内跨水平段，不能取附加筋截止符号 |
| 附加筋（仅模式4） | 自由端上方，先上后右 | 自由端上方，先上后左 | 本组在悬挑板内的真实水平段 |
| 无内跨面筋（模式1/2） | 自由端上方，先上后右 | 自由端上方，先上后左 | 面筋真实水平段 |
| 底筋 | 自由端下方，先下后右 | 自由端下方，先下后左 | 真实底筋自由端端点，避免窄板与点筋竖线重合 |
| 上下点筋 | 支座侧下方，向左 | 支座侧下方，向右 | 靠梁端一对真实竖向对齐点筋 |

点筋公共竖线从真实上排中心起，经过同X的真实下排中心，再向下到水平行转向支座侧。下排中心位于公共竖线上，两条共线分支合并为一根LINE，避免叠画；仅一条水平线及整组规格，不接两排中间空白。

实际总数Upper.Count+Lower.Count恰好2根时用2φ实际直径；超过2根用φ实际直径@输入间距，不自动附加数量。每排各2根、共4根仍用间距。不新增或移动钢筋及点筋。

## 实现与边界

功能修改仅在CantileverAnnotationGeometry；CantileverCadCommand仅更新描述注释。计算、预设、F和记录源码与5362b96一致。内跨伸出筋锚点若与附加筋截止端巧合重合，会改选同一真实内跨直段上的位置。其他模式只保留实际存在的组。

文字分别位于内跨/自由端和构件上/下方，位于所有竖直引线列以外；L/Lin尺寸保持上方分行，h尺寸继续避让同侧实测TEXT范围。CAD服务保持真实接触点、竖线和斜杠，仅延长最后水平段至文字实测终点。旧节点服务不变。

新增独立布局矩阵覆盖左右、四模式、板长150/300/1500、板厚100/200/400、字高20/62.5/150、比例1/.001/英寸和E/Lin悬殊。验证轴向线、90°转角、正确组别与位置、真实接触点、上下点筋汇合、统计口径、无交叉/重复共线LINE、文字在线上及L尺寸行留白。布局前后全部钢筋顶点/bulge、点筋坐标/数量、EffectiveF和请求记录逐项完全相同。

左右模式4纯布局预览已查看，仅检查路由；示意圆弧和字体宽度不作为CAD实测。实际测试、DLL、SHA-256及用户流程见 [验收清单](../tests/V05_RELEASE_CHECKLIST.md)。真实CAD字体、尺寸界线及图面仍待用户验收；不启动/关闭CAD、不重试隔离NETLOAD、不改安全设置，不推送、不打标签。
