# V0.5 模式④上方尺寸等高

2026-10-29，基线f215032。用户确认Lin与L是两条独立尺寸，共用同一个世界坐标Y；尺寸文字保持相同高度和样式。该要求覆盖此前L/Lin上下分行的描述。

仅在CantileverAnnotationGeometry完成现有紧凑规格布局之后，统一确定最终尺寸标高。取原L/Lin行中较高值，以及两组上方规格的实测文字上界、全部引线端点最高值加留白的最大值。留白沿用max(50mm,1.5×规格字高)，按图纸单位比例转换。随后同时更新WidthLine.Y与LinLine.Y，X坐标不变。最终标高不反馈到钢筋规格布局，避免抬高尺寸时再次推远规格。

Lin仍由内跨侧梁面量到附加筋截止位置，数值不含b；L仍由悬挑侧梁面量到自由端。不合并尺寸，不新增b尺寸，不改变尺寸定义点。两者继续调用同一个BuildBeamSideDimension服务，沿用TSSD_25尺寸样式、相同字高及单位换算。CAD命令、钢筋规格锚点/文字/引线、下方点筋/底筋、排筋、自动F、预设和记录代码未修改，旧块不自动重画。

自动验证：CantileverAnnotationTests通过87,644项，新增左右模式④共Y、两组实测规格及引线均低于共同尺寸行、L/Lin真实长度和单位换算断言；覆盖不同L/h/字高/E/Lin及宽文字样本。继续保留原布局、双排点筋、规格统计、几何/自动F/记录不变和左右对应测试。原界线断言保留到原尺寸行的路由范围；本轮新断言验证最终水平尺寸行，不将它扩大为AutoCAD原生尺寸文字、箭头和延长后界线已验收。
