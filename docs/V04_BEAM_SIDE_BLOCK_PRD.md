## 1. 目标与依据

在已验收的梁上/下、板上/下节点基础上，增加梁侧挂板。它是梁侧面伸出的混凝土块体，与梁等高或接近等高，通常宽度小于高度；不是细长悬挑板，也不是反坎顶部架挑板。

用户已确认：

- 侧向 U 形线筋与反坎相近；靠梁的连接面中部不布点筋。
- 点筋沿上边、外侧竖边、下边布置；最外侧上下角部必须有点筋；相邻中心距不超过输入间距，并尽可能少布点。
- 整组点筋可从左侧或右侧引出，规格为实际直径与输入间距，例如 `φ6@200`。
- 线筋两端进入梁内后各作一个 90° 弯折。输入梁内总长 L、竖直直段长度 V，上下端共用这两个数值。
- L 从梁侧连接面起沿钢筋中心线量至端头，包含水平直段、圆弧和竖直直段；V 为圆弧切点至端头的竖直直段长度。
- 上端和下端分别选择向上或向下弯折。默认上端向下、下端向上，允许全部四种组合。

参考 [块体示意](design-preview/beam-side-block-understanding.svg) 仅说明外形和点筋位置；其中尚未画出的梁内端部弯折以本文为准。[早期横长示意](design-preview/beam-side-plate-understanding.svg) 已被用户纠正，不能作为梁侧挂板依据。

以下标为“实施口径”的内容，是本稿为形成可执行任务作出的界面与几何细化，不冒充用户逐项确认的结构规则。

## 2. 首版范围与输入

实施口径：一个“梁侧挂板”入口、一个参数窗口，支持块体向左/向右伸出，共用计算；默认向右。图示为右侧实例，左侧按左右镜像处理，弯折选择始终指世界坐标向上/向下，不能随镜像交换。

继承当前节点的正交二维 LINE/LWPOLYLINE 输入、1 mm 识别容差、毫米单位口径及非毫米警告。保留源轮廓，不旋转/镜像原始 CAD 对象。局部闭合矩形或向梁开口的侧向 U 轮廓，由所选伸出方向确定靠梁连接面。完整模式识别规则矩形梁与相连矩形块体；梁、块体可以等高或有上下错位，但连接范围必须有效。多个候选要求点选并重新校验，禁止静默猜测。复杂梁、斜面、曲线轮廓及不连通块体拒绝并说明原因。

宽度小于高度、接近等高属于典型外形说明，不自行发明比例阈值作为拒绝条件。局部模式缺少梁背面及完整上下边界，不能宣称已验证梁内弯折容纳空间。

## 4. 连续线筋与梁内弯折

整根为一条连续宽 LWPOLYLINE：上端梁内竖直尾段，经端部圆弧及水平段，沿块体上边到外侧，经外侧上下两个圆角转至下边，再返回梁内下端弯折及竖直尾段。顶点遍历可以反向，但结果必须相同。

每端梁内中心线总长关系：

`L = a + πR/2 + V`

其中 a 为从连接面到梁内圆弧水平切点的水平直段长度。因此 `a = L - V - πR/2`，弯折竖段中心线距连接面的水平深入距离为 `a + R`。L 不包含块体内、连接面以外的水平段；V 不包含圆弧。上下端用相同 L/V/R，但弯折方向独立。

示例仅验证算术，不是工程推荐：L=400、V=100、R=20，则 a≈268.584，水平深入距离≈288.584，两端中心线展开长各为400。

校验 a>0、有效尺寸、圆弧相切、无零长度/重复边/自交。两端朝中间弯折时，检查真实几何是否相交或重叠；朝外时也校验与其他本次线筋段的冲突。不得因方向不同重新解释 L/V。未定义钢筋净距或碰撞规则时不虚构阈值，也不宣称满足结构规范。

实施口径：完整梁边界已知时，若梁内生成钢筋的显示外轮廓越出混凝土，提示具体端部/位置并阻止生成，不自动截短或移动；局部模式明确说明“梁边界未知，梁内端部需人工审核”。这属于几何容纳检查，不是锚固合格校核。

## 5. 点筋与最少根数

只在块体范围的上边、外侧竖边、下边布点；靠梁连接面中部不补点，不沿梁内尾段布点，不在块体内部自由布点。上下水平直段各自从 0 根开始判断；只固定外侧上下角点。取消固定靠梁端点和显示外缘齐平要求，不建立虚拟靠梁点筋。

延续已确认的内缘相切表达：直段点筋与线筋内缘相切，最外侧上下两个角部各有一根与对应圆弧内缘相切的点筋。角点参与相邻中心距计算，由相邻两边共用，不能重复计数。R 或空间不足以容纳点筋时拒绝生成。

用户本次补充确认宽块的边界控制：从靠梁块体边界至最近实际点筋中心的水平距离，减去点筋半径，若超过 s 则需增加水平点筋。此处半径按几何显示直径的一半处理，与相切/不重叠使用同一尺寸，规格直径仍独立。角点自身满足该距离时水平直段为 0 根；超限时才在真实水平相切直段增补。最近新增点可自由定位，不固定在连接面，也不把边界视为一根点筋。

上下边分别计算初始 `D=|角部点筋中心X-ConnectionX|-DotDisplayDiameter/2`；D≤s时新增0根，超限从角筋向梁侧按真实中心距s逐根递推。首步水平位移sqrt(s²-高度差²)，后续水平位移s；每步后重新检查实际末端边界净距，≤s即停止。取消水平空档均分，余量留在靠梁端，不强制靠梁点。300宽新坐标及旧策略比较见 [300宽核查](V04_300_WIDTH_CHECK.md)。

按实际三边开放顺序检查中心距，不跨连接面中部闭合。水平新增点的实际中心距为s，并满足真实直段、相切及不重叠；无法递推时拒绝，不调间距或角点。水平从0根起算，上下对称。外侧竖边仍在两角间按上限s求最少新增根数并优先均匀，本轮不改变其策略。测试独立测量实际距离及边界净距，覆盖0→1、1→2及连续多根。

## 6. 标注、尺寸、块

点筋整组始终为直径加输入间距，例如 `φ6@200`；不因只有一排或根数少改为 `3φ6`，不自动附加总数。实际等分间距可以小于输入值，标注仍表达用户输入的间距上限。此规则只适用于本节点，不改旧四类节点的单排标注。

线筋、点筋均从各自真实钢筋位置水平直引，TEXT 正向、在水平线上方，无箭头；标注侧由窗口独立指定。点筋优先选择最接近块体竖向中部且可排布的真实点筋，线筋规格必须在其上方，优先调整线筋在真实外侧竖直直段的接触高度。不增加或移动点筋迁就布局；没有中部实际点筋时取最接近且可排布的已有点，不能指空白。无斜向接驳段，保留交接斜杠。水平末端按实际TEXT范围截取，无法避让时明确报告标注失败。复用字体、图层及字高，允许BEDIT人工调整。

线筋规格复用现有表达；尺寸为块体实际水平宽度及竖向高度。宽度尺寸在上方；最新确认两种伸出方向的高度尺寸均在块体右侧外部，与标注侧无关，尺寸定义点取块体右边实际顶底。右侧存在文字/引线时，按实际生成的文字边界和引线右界再向外留距，不穿过文字；间隔沿用max(50mm,1.5字高)，同单位缩放。首版不另加L/V/梁尺寸及规范标注。每次生成独立普通块；源混凝土不入块，基点仍为连接面块体下端。事务、四类图层及已有样式保持原流程。
