# V0.5 两点矩形输入

2026-10-29，基线3393e76，包含此前Lin/L尺寸等高和端部长度TEXT，不覆盖已有提交。

三个绘制窗口增加输入方式，默认“选择已有轮廓”；可改为“两点矩形（仅局部）”。适用梁上反坎/梁下下挂、板上反坎/板下下挂、梁侧挂板及普通悬挑板。窗口先确定方向、模式、规格及其他参数，再依次点两个对角点。两种对角线和先后顺序均可，宽高由实际点取范围取得，不按比例猜节点。

第二点使用Editor.GetCorner原生矩形橡皮筋预示，不建立LINE、Polyline或混凝土对象。原生提示负责结束/取消预示。拾取发生在生成事务和UNDO组之前；第一点取消、第二点取消或非法矩形均直接返回/报告，不进入正式生成及成功记录写入。

## 局部几何与连接边

| 节点方向 | 连接边 | 支座信息 |
|---|---|---|
| 梁上、板上 | 矩形下边 | 局部闭合矩形，不能宣称完整支座检查 |
| 梁下、板下 | 矩形上边 | 先按NodeOrientation归一，再用原共用排筋并反射回来 |
| 梁侧/悬挑向右 | 矩形左边 | 未知完整梁边界 |
| 梁侧/悬挑向左 | 矩形右边 | 未知完整梁边界 |

RectangleInputGeometry只保存数值边界、Elevation，生成内存ContourSegment供原识别器处理。梁/板使用原Upstand/SlabUpstandRecognizer；侧板及悬挑使用原BeamSideContourRecognizer局部模式。之后进入各节点原计算、标注、普通块及成功参数事务。不存在两点专用排筋算法，不修改源图元。

板厚h仍由窗口输入，两点方式缺h在窗口拒绝；不虚构SlabLeft/SlabRight。梁侧窗口选择两点后，明确显示局部模式并禁用完整截面选项；切回轮廓方式恢复本次原模式草稿。请求构造也拒绝“完整截面＋两点”的组合。悬挑梁宽b及A/V/E/B/Lin等继续用原参数，L/h取真实矩形。无完整边界时沿用既有未知边界状态，不标记完整检查通过。

## 请求、坐标、单位

三类不可变请求增加只读TwoPointRectangle，旧调用默认false；旧节点请求另捕获单位代码。目标Document仍由命令闭包持有，选择前、两次拾取之间、拾取后及生成前核对目标与单位。无全局pending参数。输入方式只属于本次请求，不增设共享配置或改变原DWG记录格式，下次开窗仍默认轮廓选择。成功仍仅更新本类型原成功键，取消/失败不写。

两点方式限WCS轴向顶视图。允许同向平移UCS，拾取点按捕获的UCS矩阵转WCS；旋转/倾斜UCS、非顶视图和扭转视图明确拒绝，拾取中UCS改变也拒绝。点取数值须有限，两点须同WCS水平平面，计算宽高须大于既有1mm容差，溢出及近零拒绝。Elevation保留，不混用屏幕坐标。

梁侧/悬挑沿用请求中已确认的毫米换算或本次毫米解释；点取坐标除相同比例一次，生成按原服务乘回。梁上/下、板上/下保持既有固定1CAD单位=1mm流程，提示本次实际比例，不在新增输入中偷偷升级旧算法的单位语义，也不改变INSUNITS。
