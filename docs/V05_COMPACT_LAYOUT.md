## 用户确认与布局

| 组别 | 紧凑布局，左右对应 |
|---|---|
| 内跨伸出筋 | 内跨侧上方，取自己的真实内跨水平段；不取附加筋截止符号 |
| 无内跨面筋、附加筋 | 悬挑侧上方，取本组真实水平段；模式4身份和规格分别保留 |
| 点筋 | 板下方偏支座半区，选择有利于紧凑布置的一对真实上下对齐点筋；共用一条规格 |
| 底筋 | 板下方偏自由端半区，锚点可沿真实水平直段选择；允许向板中部出字 |

所有引线仍先竖直再水平，文字正向、在水平线上方，线筋交接斜杠随真实锚点移动。点筋公共竖线从上排真实中心经过同X下排真实中心，再到板下方，不重复LINE。实际总数2根仍为2φ实际直径；更多仍用φ实际直径@输入间距。各模式只标实际存在的组。

## 实现

CantileverAnnotationGeometry.Calculate只整理真实接触段、规格及初始行位。CAD复用现有BuildUpstandLabel和TSSD样式，在不提交的测量事务中读取每条DBText.GeometricExtents的实际宽高；没有按字符数估算或设置固定超长引线。测量失败明确报告，沿用可选标注失败策略，不改排筋来补偿。

ApplyMeasuredLayout接收图形单位下的实测宽高。文字近侧边距折点仅max(4mm,0.08×字高)，水平线终点为文字远侧实测边，不含整个节点包围盒造成的额外空白。内跨锚点先取靠梁的一段，不取E/2或内跨远端。E变化不推远附加筋、点筋或底筋标注。

下方布局以板内1/4、3/4位置为文字中心目标，在真实点筋对及真实底筋直段上选择接触点，比较两个水平出字方向及同高/错高行位。按实测文字矩形和轴向线段检查间隔与交叉；不足时仅错开标注高度。板下行距由板底及实测文字高度决定，不由梁内弯筋的最低范围决定。

上方若短引线文字与L自由端界线或Lin截止界线相遇，先沿对应真实直段改选锚点，斜杠同步；真实直段不足时，仅将该规格文字及水平段上移到相应尺寸行上方。L/h/Lin的起算点、测量值及尺寸行定义均保留，h尺寸仍沿用现有实测范围向外避让服务。实际原生尺寸文字、箭头及字体替代的最终外形须在CAD验收。

很短的板配很大的字时，真实文字本身可能宽于半个板长，半区中心和紧凑距离作为优先目标，不能保证整段文字均包在半区内；不缩字、不移动钢筋、不附加无依据的长留白。若仍找不到无冲突的下方布局，明确报告需人工调整标注，不静默重叠绘制。

生产改动仅CantileverAnnotationGeometry与CantileverCadCommand，复用原实体/文字/图层/尺寸/块服务。几何、排筋、点筋、DrawState、DrawForm和旧节点共用标注源码与a3bc0eb逐文件核对一致。记录格式及成功事务写入不变；未修改旧块。
