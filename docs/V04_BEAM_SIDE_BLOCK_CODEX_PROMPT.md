【用户已确认的核心】
梁侧挂板是与梁等高或接近等高、通常宽小于高的梁侧混凝土块体，不是悬挑板。
连续侧向U形线筋，两端进入梁内后各弯90°。
上下端共用总长L和竖直直段V；L从梁侧连接面沿中心线量至端头，包含水平直段、圆弧和竖直直段，V从圆弧切点量至端头。
上下弯折方向分别可选世界坐标向上/向下，默认上端向下、下端向上，四种组合都支持。
统一R复用高级设置，每端梁内水平直段a=L-V-πR/2，竖段中心线水平深入距离a+R；L不含块体内连接面以外的长度。
点筋只沿上边、外侧竖边、下边布置，连接面中部不布点，最外侧上下圆角各有点筋。保持与线筋内缘相切，在中心距不超过输入s的条件下取最少根数。
点筋整组左/右引出，始终标φ实际直径@输入间距，例如φ6@200；不套旧节点单排3φ6规则。
