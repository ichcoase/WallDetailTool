## 窗口与请求

UnifiedNodeUi只重排原NodeDrawForm、BeamSideDrawForm、CantileverDrawForm的控件；NodeDrawState、BeamSideDrawState、CantileverDrawState仍各自解释参数，CreateRequest仍生成完整不可变请求。目标文档和单位校验、选择/两点适配、普通块、成功事务保存由原命令执行。没有全局pending，没有两套排筋算法。

顶部方向/输入方式/构造；左侧组别-直径-间距表、当前模式尺寸、自动F说明及低频选项；右侧原生示意、参数焦点说明、步骤、离线帮助；底部单位与恢复/取消/生成。主体可滚动、窗口可调整，最小640×440并受当前屏幕工作区约束。生成按钮按输入方式切换，非法数字就近ErrorProvider提示，其余输入保留；隐藏字段不参加校验。涉及几何或命令失败的原错误仍保留，不新增成功通知。

原始文本草稿只属于本次窗口。梁/板方向沿用NodeDrawState；梁侧/悬挑新增窗口内模式字典，独立保存模式原始文字，左右方向共享该模式输入。恢复只影响当前启用数字；取消不返回请求。共享高级设置仍从既有工具条打开，不另存储。

焦点说明使用已确认定义，原生System.Drawing覆盖尺寸线标识，随上下/左右/四模式变化；符号不按输入比例缩放。板H从板底/板顶起，梁锚固左右分别高亮，梁侧L表示包含端部的路径而V只标直段，悬挑V为投影。示意仅辅助理解，不是CAD预览。帮助直接从当前窗口显示本地原生示意及参数/步骤/限制，内容编译进DLL，无联网/浏览器或额外帮助文件部署依赖。六类审阅示例见[帮助索引](help/README.md)。

## 标注共性复用与特例保留

本轮核对后复用既有生产标注服务，不重写已验收布局；以下生产计算/标注文件与5fef3cb保持内容一致。新增界面高亮不参与CAD标注计算。

| 共性/节点 | 既有实现及保留行为 |
|---|---|
| 原生TEXT/字体/交接斜杠/实际范围 | RebarAnnotations与节点命令的既有创建/实测TEXT服务；字高、图层及统一数值格式继续取原设置 |
| 梁上/下、板上/下 | UpstandAnnotationGeometry及NodeOrientation；上下共用原计算，文字正向，既有引线/尺寸关系不变 |
| 梁侧挂板 | BeamSideAnnotationGeometry；保持水平引出、真实点筋锚点、自动/手动标注侧及高度尺寸侧别；实际文字范围参与避让 |
| 普通悬挑板 | CantileverAnnotationGeometry；紧凑90°、四区布局，真实上下点筋公共连接只一条规格；两根仍数量表达；按实际TEXT范围定水平段，不随E整体推远 |
| Lin/L | 模式④共同尺寸Y，并共同避开上方两组规格/引线；独立数值/起算点，不含b |
| 端部长度 | EndLengthAnnotationGeometry/Cad；原生0/90°纯数值，悬挑V投影、板L直段、梁侧V直段分别保留；不加自由端F |

共性样式已存在，故没有为了“统一”新增另一套样式或强制一种引线。避让继续只调整标注，绝不移动钢筋或点筋；无法合法放置时保留现有非关键标注失败说明。实测范围需要真实CAD字体参与，独立自动测试不等于真实图面全部无冲突。历史块不自动改变。
