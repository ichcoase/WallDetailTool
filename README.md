# WallDetailTool

## 梁上反坎第一版（待 CAD 实测）

若自动角色识别不唯一，请依次点选梁、板、反坎；人工指定后不要求板跨梁、梁宽大于梁高或三条边完全齐平。钢筋按所选反坎与梁生成，板只绘制混凝土轮廓。

加载本轮交付的 DLL 后，在新图或图纸副本中输入 `WDTUPCONTOUR`，框选典型梁、板、反坎轮廓。命令接受三个闭合轴对齐矩形多段线，或每个矩形由四条独立直线组成；识别唯一时创建红/绿/蓝色工作轮廓，不修改建筑原图。可用 CAD 夹点、MOVE、STRETCH 修正工作轮廓。输入 `WDTUPDRAW` 依次选择梁、板、反坎工作轮廓，按提示输入配筋与两侧**经设计确认**的伸梁长度，检查红色预览，可选择修改或取消。确认预览后指定新大样梁左下角插入点。新图初始模板为 U 筋 φ8@150、点筋 φ6@200；确认生成后本 DWG 记住参数，取消不保存。`WDTUPDOTSIZE` 可设置当前 Windows 用户的圆点筋图形显示直径（默认 12 mm），与线筋显示宽度和计算直径独立。

结果包含独立混凝土轮廓、倒 U 形宽多段线、两列闭合多段线圆点筋、规格/间距文字和三处基本尺寸，按类型分层；一个 `UNDO` 应撤销整次生成。锚固长度不会自动按规范推算，超出梁高时不生成。本版只适用于典型二维正交矩形节点；CAD 内实际显示、保存和撤销仍需用户验证。现有 `WDTREBAR`、`WDTPANEL` 等命令保留。旧版说明中的 Phase7 路径是历史交付，不代表本轮 DLL。

AutoCAD 2023/2024 C# 插件，.NET Framework 4.8 / x64。

## 加载及使用

1. 如果当前 AutoCAD 已加载旧版 DLL，请保存图纸并重启 AutoCAD。
2. 输入 NETLOAD，选择 D:\Waste\WallDtailTool\bin\Phase7\WallDetailTool.dll。
3. 如有信任路径提示，按 AutoCAD 提示信任本项目的 bin\Phase7 目录。
4. 输入 WDTPANEL 打开侧边栏。在新图中先填节点名称、保护层和直径，点击“新建节点”；选中节点后填钢筋组名称，点击“新建钢筋组”。选中钢筋组，从“目标钢筋图层”选择图层或输入新名称，再点击“选择轮廓并预览”，在图中选择二维多段线并点选偏移方向。红色线仅是临时预览，点击“确认生成”后才写入图纸和关联数据；新图层会先询问是否创建。“取消预览”不留正式对象。
5. 树形列表显示节点→钢筋组→钢筋。选中一条钢筋后，可修改保护层、直径或目标图层，点击“预览修改所选钢筋”，检查红色结果和提示，再点击“确认修改”。修改保护层或直径会按原轮廓重新计算中心线；旧版钢筋若没有源轮廓记录，会提示重新选择轮廓和方向。只改图层会保留现有路径。CAD 中手工改过路径时，重新计算前会提示将替换该形状。取消预览不改图纸；确认后可以用 AutoCAD 撤销。
6. 选中列表中的钢筋，在“钢筋直径标注文字”输入所需文字，例如“Φ8@200”。点击“预览直径标注”，在图中点选钢筋上的引出位置，再点选文字下方横线的末端（文字右端），检查红色预览，再点“确认直径标注”。竖向段会自动把横线对齐引出点高度；水平段请将文字点放在钢筋上方或下方，以形成直角折线。已有标注时改输入框文字，再预览、确认，只改文字。若要调整旧标注位置和引线，点击“调整已有标注引线”重新选点、预览、确认。每条钢筋目前限一条关联标注。
7. “刷新列表”可查看 CAD 中删除、手工调整或撤销后的状态；“在列表定位钢筋”可选择图中钢筋并找到对应条目。选中节点或组后可修改名称及默认保护层/直径，再点击“保存所选节点/组的名称与默认尺寸”。组继承创建时所选节点的默认尺寸，新筋使用所选组的默认尺寸；输入框手动更改后仅影响本次新筋。修改默认值不会改变已有钢筋。
8. 也可继续使用 WDTREBAR 命令直接生成；此旧命令生成的钢筋目前不会自动加入层级，故不能用面板为其建立关联标注。
9. WDTTEST 保留，输出 WallDetailTool loaded successfully!。

WDTREBAR 的操作：

1. 选择开放式、纯直线段的二维多段线。
2. 输入保护层厚度（默认 25 mm）和钢筋直径（默认 12 mm）。
3. 在线段中部旁点选所需的一侧；线上、端点或等距拐角处需重新点选。
4. 生成独立的钢筋多段线，原轮廓保持不变。默认宽度 12 mm、中心线偏移 25 + 12 / 2 = 31 mm。

输入尺寸始终为毫米，按图纸 INSUNITS 换算。未设单位时会提示按 1 图形单位 = 1 mm 处理。
支持轻量二维多段线和非拟合的旧式二维多段线；支持轮廓平面法向和标高。
WDTREBAR 不支持圆弧、闭合轮廓、三维或拟合多段线，也不自动生成弯钩、锚固或标注；插件不做结构安全校核。
直径标注使用当前图纸中名为 TSSD 的文字样式，字高 62.5 mm；文字、引线和交接斜杠均在 S-TEXT。按引出点处的局部线段判断：竖向段水平直引，水平段先竖直再水平，横线到文字右端；斜向段暂按直角折线处理。交接斜杠宽 10 mm、长 37.5 mm。缺少 TSSD 样式时会提示，不会擅自换字体。样图给出的 TSSD_25 是尺寸标注样式，本次没有创建尺寸标注实体；s-floor_de_dim 与 S-THIN 暂不用于直径标注。缺少目标图层时会先询问是否新建，已有图层的颜色等属性保持原样。
侧边栏新生成的节点、组、钢筋和直径标注关联保存在当前 DWG 中。预览期间若相关对象或参数变化，确认会拒绝并要求重新预览。切换/关闭图纸时清除预览。删除钢筋后关联暂留并显示“已删除”；若有标注，则显示“标注待处理”，当前不会自动清理文字和引线。CAD 中直接改标注文字后，刷新列表可看到实际文字及“文字已手改”。复制及跨图复制规则尚未实现。新版标注界面仍待人工验收。

## 安全检查

使用 AutoCAD 原生 GetOffsetCurves，不自行计算偏移折线。
源轮廓仅以只读方式打开，所有处理使用临时副本；检查完成后才提交新实体。
检测零长度/过短线段、无效坐标、自交、非相邻接触、重叠和折返。
偏移结果必须是一条开放直线多段线，且线段没有消失；否则取消生成。
检测结果与原轮廓之间的穿越及间距不足。复杂轮廓可能被保守拒绝，应调整轮廓或距离。
几何距离容差为 0.000001 图形单位；间距校验还考虑偏移距离的数值误差。

## 编译

使用本机 AutoCAD 2023 的 AcMgd.dll、AcDbMgd.dll、AcCoreMgd.dll，引用不复制到输出。
使用现有 Visual Studio 2022 MSBuild 和 .NET Framework 4.8 Developer Pack。

powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -OutputPath bin\Phase7\

本次新版输出到 bin\Phase7。AutoCAD 同一会话不能可靠地卸载或替换已经加载的同名 .NET 插件，应重启后加载新版。

## 文件

- Commands.cs：WDTTEST。
- RebarCommands.cs：WDTREBAR、输入及原生几何检查。
- RebarPalette.cs：WDTPANEL 侧边栏、临时预览、确认与取消。
- DrawingData.cs：节点、组、单筋、直径标注的 DWG 记录、稳定标识及版本检查。
- RebarEditing.cs、RebarEditService.cs、LayerTools.cs：修改预览、事务提交与目标图层。
- RebarAnnotations.cs：直径文字、直角引线和短粗斜杠的预览、提交、位置调整及文字编辑。
- WallDetailTool.csproj：项目配置。
- build.ps1：编译脚本，支持指定输出目录。
- tests/GeometryTests.cs、GeometryTests.csproj：独立原生几何测试程序集，不编入正式插件。
- tests/geometry.scr：控制台测试脚本，包含几何测试、WDTREBAR 默认参数及 WDTTEST。
- tests/PersistenceTests.cs、phase3.scr、phase3_reopen.scr：独立的层级、编辑、撤销重做、删除、版本防护及重开验证代码/脚本。
- tests/EditTests.cs、phase4*.scr：独立的编辑、图层、旧数据兼容及撤销重做验证代码/脚本。
- tests/AnnotationTests.cs、phase5_label*.scr：直径标注、文字独立修改、撤销重做及保存重开验证代码/脚本。
- tests/phase6*.scr、rebar-annotation-proposal.svg：新版引线布局的隔离测试脚本与示意图。
- tests/phase7_save_*.scr、phase7_layout_*.scr：本次标注布局保存重开、撤销重做的专用隔离测试脚本。

测试脚本应仅在独立的 accoreconsole /isolate 配置运行，因为它为测试 DLL 设置了受信任路径；不应在日常工作图纸中运行。
测试只保存专用测试 DWG，不覆盖用户图纸，也不修改 AutoCAD 安装目录。测试结果及仍需人工核验的界面项目见 TEST_RESULTS.md。
